# Fuentes para las imágenes de compartir

Instancias estáticas de **Archivo** (Google Fonts, licencia SIL Open Font
License 1.1), descargadas en formato WOFF para `ImageResponse` de Next, que no
lee fuentes variables ni WOFF2:

- `archivo-extra-condensada-700.woff`: ancho 62,5 %, peso 700. El titular.
- `archivo-semiexpandida-500.woff`: ancho 112,5 %, peso 500. Los rótulos.

Las usan los archivos `opengraph-image.tsx` de `src/app/(tienda)`.
